知识点：长链剖分优化 DP、树套set

261/400

## A 种花

显然要把连续的一段区间连在一起，直接双指针即可。

## B 游戏

将所有区间按 $c$ 排序，显然选的肯定是一段区间，考虑用双指针求出以每个 $i$ 为左端点时右端点最小是多少。那么我们考虑维护当前每个关卡是否能通过。具体地，我们在每个关卡开个 set 维护能使用的药水集合，那么若每个关卡 set 药水 $v$ 的最大值都 $\ge h$ 即满足条件。发现每次的修改是区间的，考虑用线段树套 set 维护。这样在线段树每个节点维护还没有满足条件的关卡中 $h$ 最大值即可。

发现这样是 $2\log$ 的，但是 set 可以换成单调队列变为 $1\log$。

## C 驻军

设 $dp_{x,i}$ 表示 $x$ 子树内链顶为 $x$，长度为 $i$ 的链到子树内所有点的距离和。转移就类似树形背包。这样是 $O(n^2)$ 的。

然后发现第二维与深度相关，用长剖优化到 $O(n)$。

长剖优化 dp：找到 $x$ 的长儿子，因为 dp 状态的深度只相差 $1$ 可以用指针 $O(1)$ 赋值。其他儿子直接按上面的转移暴力即可。这样每个点只会在所在长链顶的父亲被统计一次，复杂度 $O(n)$。

## D 序列

发现 $\gcd(x,x+v)=\gcd(x,v)$，也就是要查询 $k$ 时刻的 $a_p$ 值与 $k\sim i$ 时刻在这里加过的所有 $v$ 的 $\gcd$。

发现是单点查询，考虑离线下来维护。我们从左到右枚举序列的每个位置 $i$，处理所有落在这个点上的询问。同时，我们维护在每个时刻 $a_i$ 的值和每个时刻是否有在这里插入一个 $v$。前者可以差分后将后缀加转换为单点加求前缀和并用树状数组维护，后者直接在线段树上单点修改，区间 $\gcd$，因为是区间求 $\gcd$ 均摊下来是 $O(n(\log n+\log v))$ 的。
