## A CF1716F Bags with Balls

总和转期望。（转不转都一样）

枚举奇数标号的球的数量 $i$，那么在一个袋子里得到奇数个球的概率为 $p=\dfrac{\lceil\frac{k}{2}\rceil}{k}$。那么期望为：

$$\sum_{i=0}^ni^Cp^i(1-p)^{n-i}\dbinom{n}{i}$$
$$=p^n\sum_{i=0}^ni^C(\frac{1-p}{p})^{n-i}\dbinom{n}{i}$$

这个形式似曾相识啊。

套用 [P6031](https://www.luogu.com.cn/blog/yangsonghan/ti-xie-p6031-post) 的推法，令 $m=\frac 1p$ 即可。

最后乘上 $k^n$ 即为答案。

## B CF1809G Prediction

遇到困难先转化。

先用式子表示出限制：$\forall i\in 1\sim n,|b_i-\max_{j=1}^{i-1}b_j|>k$。

看到里面有前缀最大值，考虑以此为线索进行 DP 的设计。

先预处理出 $l_i,r_i$ 分别为左边和右边第一个绝对值之差 $>k$ 的位置。

那么对于所有前缀最大值的位置，我们从后往前考虑：

对于第 $i$ 个前缀最大值，设其原位置为 $p_i$，则所有下标在 $l_{p_i}+1\sim n$ 的数（除掉 $p_i$）都应该放在 $p_{i+1}$ 之后，并且 $r_{p_i}\le p_{i+1}$（否则显然不符合条件）。对于最后一个前缀最大值特殊，因为可以在它的后面随便放，方案数为 $(n-l_{p_i}-1)!$，而对于其它的 $i$，因为 $l_{p_{i+1}}+1\sim n$ 已经放好了，只需要放 $l_{p_i}+1\sim l_{p_{i+1}}$ 除去 $p_i$，由上面的限制知道一开始一共有 $n-l_{p_{i+1}}$ 个空位，并且每次放进去后又多一个空位，所以方案数为 $n-l_{p_{i+1}}\sim n-l_{p_i}+2$ 的积。

统计一下就是 $(n-1)!/\prod_{i=1}^{m-1}(n-l_{p_i}-1)$。

那么我们只需要求出所有方案中除号后面的乘积的倒数和，这个可以简单 DP 求出。具体地，从后往前 DP，设 $dp_i$ 表示前缀最大值第一个位置在 $i$ 的倒数和。前缀和优化即可。

## C CF913F Strongly Connected Tournament

很好的 DP 题。

发现一个竞赛图缩点后是一个 DAG，并且只有一个没有出度的强连通分量。考虑以此为线索，进行大致的 DP 刻画思路。

状态很好设，$dp_i$ 表示大小为 $i$ 的竞赛图期望进行轮数。

但是此时有新的问题：

- 有可能缩点后自己还是一个强连通分量，需要求出这方面的概率。

- 大致计划是枚举那个没有出度的强连通分量大小，但这样那个单独的强连通分量的 DP 定义与上面的定义不完全相同。

先解决第一个：设 $f_i$ 表示大小为 $i$ 的竞赛图是一个强连通分量的概率。转移考虑容斥，还是枚举无出度的强连通分量大小，只要满足大小 $<i$ 就代表整个图有多个强连通分量。

所以转移式为：

$$f_i=1-\sum_{j=1}^{i-1}f_j\times to_{i,j}$$

其中 $to_{i,j}$ 表示 $i$ 个点中选出 $j$ 个满足它们和剩下 $i-j$ 个之间的边都是指向自己的概率。这个也可以递推，枚举第 $i$ 个属不属于那 $j$ 个点即可。

$$to_{i,j}=to_{i-1,j-1}*p^{i-j}+to_{i-1,j}\times (1-p)^j$$

然后是第二个。我们设 $g_i$ 表示下一次比赛会在所有人之间的期望轮数，则原来的 $dp_i$ 就表示下一次比赛会在上一次比赛的结果（缩完点）下进行比赛的期望轮数。

那么转移就可以写出来：

$$g_i=\frac{1}{1-f_i}\left(\binom{i}{2}+\sum_{j=1}^{i-1}f_jto_{i,j}(g_j+dp_{i-j})\right)$$

$$dp_i=g_if_i+\sum_{j=1}^{i-1}f_jto_{i,j}(g_j+dp_{i-j})$$

首先 $g$ 由于可能一直有 $f_i$ 的概率连出整一个 SCC，所以要乘上 $1+f_i+f_i^2+\cdots=\frac{1}{1-f_i}$，然后是比一次赛加上枚举出度为 $0$ 的强连通分量转移。而 $dp_i$ 则是上一次比赛有 $f_i$ 的概率是一整个 SCC，剩下转移类似。

## D CF1558F Strange Sort

新颖的思路：将一个数组排序，就是对于每一个后缀 $i\sim n$ 里都包含所有排名在 $i\sim n$ 的数。

也就是对于每个 $k\in 1\sim n$，将数组的权值设为 $[a_i\ge k]$，则要满足所有 $0$ 在所有 $1$ 之前。那么在这题里就是对所有 $k$ 对应的 $01$ 序列排好序的次数取 $\max$。

剩下的可以看 [这篇题解](https://washeng.blog.luogu.org/blog026)。
