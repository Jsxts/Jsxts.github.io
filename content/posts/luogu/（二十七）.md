## A CF1221G Graph And Numbers

考虑容斥，每个至少都有一个容斥成所有减去只有 $\{0,1\},\{1,2\},\{0,2\}$ 的加上只有 $\{0\},\{1\},\{2\}$ 的再减去都没有的，都没有的显然为 $0$。

- 只有 $\{0,1\},\{1,2\}$：所有只有 $\{0,1\}$ 的方案权值翻转会一一对应一个只有 $\{1,2\}$ 的，两个方案数相同。发现 $n=40$，考虑折半搜索，对于 $1\sim \dfrac n2$ 的点 dfs 出所有在它们之间合法的方案状压在数组中，对于 $\dfrac n2 +1\sim n$ 的点也进行一次 dfs ，在使它们之间合法的同时记录可以是 $1$ 的在 $1\sim \dfrac n2$ 中的点形成的状态 $S$（即若一个 $\dfrac n2 +1\sim n$ 的点权值为一，相邻的权值都必须为 $0$。）发现对于这次 dfs 每一个答案为 $\sum_{i\in S}f_i$，其中 $f_i$ 表示 $1\sim \dfrac n2$ 的点选取状态为 $i$ 的方案数。复杂度 $O(n\times 2^{\frac n2})$。

- 只有 $\{0,2\}$：对于每个连通块必须全部是 $0$ 或 $1$，答案为 $2^{\text{连通块数}}$。

- 只有 $\{0\},\{2\}$：每个有边的连通块必须全为 $0/1$，单独一个点可以为 $0$ 或 $1$，答案为 $2^c$，$c$ 为孤点个数。

- 只有 $\{1\}$：每个连通块都必须是二分图，若有一个不是就是 $0$ ,否则为 $2^{\text{连通块数}}$。

## B Arkady and Rectangles

从上往下扫描线，考虑维护每行被看到过的颜色。

那么在一行的每个点上可能有若干个颜色涂在了上面，但最终只有最大的被看到。我们用 set 维护每个节点的颜色。发现修改是区间的，于是在 set 外面套一层线段树，区间修改就在对应的 log 个区间的 set 插入该数，则每个叶子的颜色为线段树中从根到它的路径上 set 最大值的最大值。

现在考虑如何更新未统计的颜色。在线段树上每个节点 $x$ 维护 $x$ 到其子树被统计过的每个叶子的路径最大值的最小值 $mn_x$（还未删除的），这样加入一个点时就可以判断它是否大于它并更新。

但是还有删除操作。此时可能会出现多个可以被统计的新颜色。于是我们还要维护一个新的变量 $mx_x$ 表示在 $x$ 子树中还没有被统计并**可能被统计**的最大颜色，可以在 pushup 时顺便维护。那么若 $mx_x<mn_x$，即还存在的颜色中最小的颜色都会比 $mx_x$ 大，那么这棵子树内就不可能有一个点会出现新颜色，直接将 $mx_x$ 置为 $0$ 即可。

最后，若 $mx_1\neq 0$，则 $mx_1$ 这个颜色将会被统计到，此时将 $mx_1$ 标为已统计，并使所有它对应的区间再次计算 $mx$。每个颜色只会被统计最多 $1$ 次，所以复杂度为 $O(n\log^2n)$。

## C CF1523H Hopping Around the Array

首先发现如果从每个位置 $i$ 开始跳，必定会跳到一个 $j\in [i,i+a_i]$ 并满足 $j+a_j$ 在 $[i,i+a_i]$ 中是最大的。而删去 $k$ 个点就是一开始走到 $i+a_i+k$。

所以可以倍增优化这个贪心，即设 $f_{i,j,k}$ 表示从 $i$ 开始走 $2^j$ 步，删去至多 $k$ 个点时可以到达的最远距离。转移为 

$$f_{i,j,k}=\max_{k1+k2=k}\max_{s=i}^{f_{i,j-1,k1}}f_{s,j-1,k2}$$

可以用 ST 表优化转移。

有了这个，对于一次询问，我们考虑二分步数，即采用倍增的方式从高位往低位，若这一位不得不选就选上。那么我们可以在询问的同时记录一个辅助数组 $ans_{j,k}$ 表示考虑完 $2^j\sim 2^{\log n}$ 步后删了不超过 $k$ 个点达到的最远距离。转移类似：

$$ans_{j,k} = \max_{k1+k2=k}\max_{s=l}^{ans_{j-1,k1}}f_{s,j-1,k2}$$

也可以用 ST 表优化。但是我们发现同样的 ST 表被预处理了很多次，导致复杂度爆炸，于是我们将询问离线下来一起处理即可。

$O((n+q)(k^2\log n+k\log^2 n))$。
